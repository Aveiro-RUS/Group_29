# PS Price Compare

Сайт для сравнения цен игр PlayStation в разных регионах, аналогичный xbox-now.com.

## 🎮 Функциональность

- **Поиск игр**: Поиск по названию, жанру или издателю
- **Сравнение цен**: Цены в 15+ регионах PlayStation Store
- **Двойная валюта**: Отображение цен как в местной валюте, так и в долларах США
- **Сортировка**: По цене (возрастание/убывание), региону, названию
- **Фильтрация**: По типу валюты
- **Лучшие цены**: Автоматическое выделение самых выгодных предложений
- **Адаптивный дизайн**: Оптимизирован для всех устройств

## 🚀 Запуск проекта

1. Скачайте все файлы проекта
2. Откройте `index.html` в браузере
3. Или запустите локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve .

# PHP
php -S localhost:8000
```
